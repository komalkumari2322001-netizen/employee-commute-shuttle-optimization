# 🗄️ SQL Analysis

## 📌 Purpose

This section uses SQL to analyze employee transportation data and identify important business insights.

## 🔎 Analysis Areas

- Employee Demand
- Route Analysis
- Booking Analysis
- Vehicle Analysis
- Trip Analysis
- Cost Analysis
- Incident Analysis

## 📊 SQL Concepts Used

The project uses beginner-friendly SQL concepts:

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- COUNT()
- SUM()
- AVG()
- LEFT JOIN

## 🎯 Business Objective

The SQL analysis helps identify transportation demand, route performance, vehicle usage, vendor activity, transportation costs and operational incidents.
