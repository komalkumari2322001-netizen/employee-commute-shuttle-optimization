# 🔎 SQL Business Questions

## 📌 Purpose

SQL was used to analyze transportation data and answer important business questions.

## 👥 Employee Analysis

1. How many employees are using the transportation service?
2. Which departments have the highest number of employees?
3. Which pickup locations have the highest employee demand?

## 🚌 Route Analysis

4. Which routes have high demand?
5. Which routes have low demand?
6. How many routes are available for each demand level?
7. Which routes have the highest number of bookings?

## 🚐 Vehicle Analysis

8. How many vehicles are available?
9. How many vehicles are provided by each vendor?
10. What types of vehicles are being used?

## 🛣️ Trip Analysis

11. How many trips were completed?
12. How many trips were cancelled?
13. Which vendor handled the highest number of trips?

## 💰 Cost Analysis

14. What is the total transportation cost?
15. What is the average cost per trip?
16. Which vendor has the highest transportation cost?

## ⚠️ Incident Analysis

17. How many transportation incidents occurred?
18. What type of incident occurs most frequently?
19. Which incident severity is most common?

## 🎯 Business Objective

The SQL analysis helps identify:

- High-demand locations
- High-demand routes
- Low-demand routes
- Vehicle and vendor usage
- Transportation costs
- Trip performance
- Common operational incidents

These insights will be used for the Power BI dashboard and business recommendations.
