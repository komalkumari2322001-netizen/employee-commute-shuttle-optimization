# 📊 Excel Analysis

## 📌 Purpose

This section analyzes employee transportation data using Microsoft Excel to identify operational issues, calculate KPIs and generate business insights.

## 📊 Analysis Areas

- Data Validation
- Transportation KPIs
- Route Analysis
- Vehicle Utilization
- Business Findings

## 🎯 Key KPIs

- Vehicle Utilization %
- Average Delay
- On-Time Performance %
- Cancellation Rate
- Average Trip Cost
- Total Transportation Cost

## 💡 Outcome

The Excel analysis identifies demand patterns, vehicle utilization issues, delays, cancellations and cost-related opportunities.

These findings will be used for SQL analysis and the Power BI dashboard.

## 🛠️ Tool

**Microsoft Excel**
