# 📝 User Stories

## 📌 Purpose

This section defines user stories for the Employee Commute & Corporate Shuttle Optimization System.

## 🎯 User Stories Covered

The project contains 10 user stories covering:

- Employee demand
- Vehicle utilization
- Capacity optimization
- Waiting time
- Delays and OTP
- Cancellations
- Route & vehicle performance
- Transportation cost
- Vendor performance
- Management dashboard

## 🔗 Requirement Mapping

User stories are linked with:

**Business Requirements → Functional Requirements → User Stories → Acceptance Criteria**

Example:

**BRQ-002 → FR-002 → US-002 → AC-002**
