# 📊 Transportation Dataset

Synthetic dataset for the Employee Commute & Corporate Shuttle Optimization System.

## Files
- Employees.csv
- Vehicles.csv
- Routes.csv
- Trips.csv
- Bookings.csv
- Incidents.csv
- Data_Dictionary.csv

## Relationships
Employees → Bookings
Routes → Trips
Vehicles → Trips
Trips → Bookings
Trips → Incidents

## Analysis Areas
Demand | Vehicle Utilization | Route Utilization | Waiting Time | Delays | OTP | Cancellations | Cost | Vendor Performance

## Tools
Excel | SQL | Power BI
